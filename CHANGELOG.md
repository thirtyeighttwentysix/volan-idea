## [0.2.0] - 2026-10-01

First public release of Volan Schema for IntelliJ IDEA 2026.1.x.

- Smart completion for schema blocks, types, database attributes and defaults.
- Relations suggest compatible foreign keys and ordered primary/unique composite keys.
- Completion suppresses duplicate or incompatible attributes and considers database providers.
- Contextual popup, useful field templates and insertion into existing parentheses.
- Syntax and semantic diagnostics from the Volan engine, quick documentation and navigation.
- Canonical whole-file formatting, folding, braces and line comments.
- Supplied Volan logo as file and plugin icons, including dark theme variants.
- Independent vendored engine snapshot with Apache-2.0 attribution.
- Automated tests, compatibility verification, signed GitHub Releases and Marketplace updates.
